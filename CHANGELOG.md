# Changelog

O que entrou em cada versão do Kiwi Notes, a mais nova primeiro. Cada linha é um PR mergeado, no formato das notas dos releases (spec #13879). As versões até a rc19 eram `v0.1.0-rcN`; a próxima é a primeira no formato `ANO.MÊS.N`.

Os arquivos de cada versão, assinados e notarizados, estão em [Releases](https://github.com/kiwi-init/kiwinotes/releases).
