# Kiwi-cat no Rive

`referencia-final.png` é a **imagem de referência final aprovada pelo harry** (#3636, #3666 e #3677): a opção 3 do #3626 com a pose corrigida, o corpo esticado até o rabisco dele (#3635). É a referência original, sem espelhar e sem redesenhar, sobre preto, com uma luz que só existe perto do gato, para a silhueta aparecer. A imagem é a pilha das camadas `literal/` (luz, corpo, cabeça e olhos) do T3151.

A animação do Rive (T3151, spec #3133) parte desta imagem. O roteiro e as camadas vêm no PR do T3151.
