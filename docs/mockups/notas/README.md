# Mockups da janela Notas (#1133)

Três opções para a janela de notas do spec "Kiwi Notes: o app de notas" (#1107), para o harry escolher na sala #ui/ux.
São telas estáticas em HTML/CSS com os tokens do app (`app/ui/src/styles/tokens.css`); nada roda nem sai do Mac.

Para ver: abra `index.html` no navegador (`open docs/mockups/notas/index.html`). No topo dá para trocar entre a
visão geral e as opções A, B e C, e entre claro e escuro (teclas `1`–`4` e `D`).

- **A · Papel**: só o texto, no estilo do Bear e do iA Writer.
- **B · Oficina**: três painéis, perto do Obsidian.
- **C · Fluxo**: centrado no ditado, com a linha do tempo do dia.

A nota de exemplo é inventada.
